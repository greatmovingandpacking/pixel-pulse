# Pixel Pulse

Live resource monitor for Google Pixel phones. Built for a Pixel 10 Pro.

## Download and sideload

**Install page:** https://jolly-bugle-ntfv.here.now/

**Direct APK:** https://jolly-bugle-ntfv.here.now/pixel-pulse-1.0.0.apk

On your Pixel:

1. Open the link in Chrome.
2. If Chrome warns you, tap **Download anyway**.
3. Open the file, allow installs if asked, then tap **Install**.
4. Open **Pulse** from the app drawer.

The app is on-device only. It shows battery and charge speed (watts), CPU, RAM, network, storage, and thermals.
